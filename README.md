VisitFlow v22

Виправлення правил ручного дня посадки:
- Рем: 2 дні до посадки = «Підг.», перші 7 днів = «п», далі тижні 1…18;
- починаючи з 19-го тижня для Рем комірки стають порожніми, бо птиця переведена на Прод;
- Прод: тижні 19…64;
- після 64-го тижня для Прод комірки стають порожніми — санрозрив;
- порожні комірки не змінюють дати посадки та не продовжують нумерацію тижнів;
- імпорт/експорт залишено тільки в «Налаштування → Імпорт / Експорт даних», у Матриці лишився тільки перегляд та «Розгорнути по днях».

Після заміни файлів натисніть «Налаштування → Очистити кеш PWA» або зробіть hard refresh.
