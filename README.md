VisitFlow v18

Нове:
- ручне коригування категорії дільниці через день посадки;
- кнопка «Категорія / посадка» у Плані та Записі;
- коригування зберігаються у state.sectionOverrides і мають пріоритет над тижневою циклограмою;
- у вкладці «Матриця / всі дільниці» тижневий вигляд лишається основним, але кнопка «Розгорнути по днях» показує щоденну циклограму;
- щоденну циклограму можна експортувати в Excel та імпортувати назад;
- при імпорті денної циклограми читається колонка «Ключ дільниці» та «День посадки» й оновлюються ручні коригування;
- кожен день маркується тижнем/станом з урахуванням ручної посадки.

Після заміни файлів натисніть «Налаштування → Очистити кеш PWA» або зробіть hard refresh.
