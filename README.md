VisitFlow v23

Виправлення правил ручного дня посадки та переведення:
- Рем активна до 19 тижня включно. Порожньо починається після 19-го тижня, тобто з 20-го;
- 19 тиждень Рем і 19 тиждень Прод залишаються активними;
- при введенні дня посадки для Рем потрібно вибрати, на яку саме Прод переводиться птиця: Рем 6 → Прод 11 або Прод 12 тощо;
- два варіанти Прод показуються радіокнопками, а найближчий до поточної циклограми вибирається за замовчуванням;
- при введенні/редагуванні Прод можна вказати Рем-джерело та дату вивезення перед санрозривом;
- якщо дата вивезення порожня — правило Прод 19…64 працює без змін;
- після дати вивезення або після 64 тижня Прод комірки порожні;
- порожні комірки не змінюють дати посадки та не продовжують тижні;
- імпорт/експорт залишено тільки в «Налаштування → Імпорт / Експорт даних».

Після заміни файлів натисніть «Налаштування → Очистити кеш PWA» або зробіть hard refresh.
