VisitFlow v13

PWA-додаток для планування та журналювання відвідувань виробничих дільниць з перевіркою матриці біобезпеки.

Оновлення:
- застосунок перейменовано на VisitFlow;
- додано вкладку «Допомога» з деталізованим мануалом;
- автопідвантаження cycle.xlsx і workers.csv адаптовано для GitHub Pages та кешу PWA;
- список працівників у налаштуваннях сховано за кнопкою;
- список працівників відкривається в модальному вікні з пошуком;
- додано можливість видаляти працівників зі списку без видалення історії журналу та планів.

Після заміни файлів у репозиторії бажано один раз виконати:
«Налаштування → Очистити кеш PWA» або hard refresh браузера.
