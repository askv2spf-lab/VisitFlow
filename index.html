Допомога VisitFlow

Цей розділ пояснює призначення кожної вкладки, поля, кнопки та службових повідомлень. VisitFlow працює як локальний PWA-додаток: дані зберігаються у браузері, а циклограма та список працівників можуть автоматично підтягуватися з файлів у репозиторії GitHub Pages.

1. Загальна логіка роботи

  1. Циклограма визначає стан кожної виробничої дільниці на вибрану дату: тиждень, сервісний стан, розгазація, посадка або службові позначки.
  2. Матриця біобезпеки перевіряє, чи може працівник переходити з однієї категорії дільниці на іншу, і показує найближчу дозволену дату.
  3. План використовується для майбутніх поїздок, а Запис — для фактичного журналу виконаних відвідувань.
  4. Обрані працівники та дільниці піднімаються вгору у списках вибору.

2. Вкладка «Сьогодні»

Дата

  • Велика дата — поточна дата пристрою.
  • Діапазон циклограми — тижневий період, у який потрапляє сьогоднішня дата.

Стан на сьогодні

  • Показує працівників і дільниці, які мають план або факт на сьогодні.
  • Якщо поїздок немає, показується «Немає поїздок».

Поїздки на сьогодні

  • Факт — запис уже внесений у журнал.
  • План — запис можна перенести в журнал кнопкою «Записати в журнал».
  • Примусові записи підсвічуються як проблемні.

3. Вкладка «Запис»

Використовується для внесення фактичного відвідування.

Поля

  • Дата — дата фактичного відвідування.
  • Виробнича дільниця — пошук дільниці; кнопка «Обрати» відкриває повний список.
  • Працівник — пошук працівника; кнопка «Обрати» відкриває список.
  • Категорія — заповнюється автоматично після вибору дільниці.

Кнопки та статуси

  • Зберегти — додає факт або оновлює запис.
  • ДОЗВОЛЕНО — працівник може відвідати дільницю.
  • ЗАБОРОНЕНО — матриця вимагає очікування; показується дата «Доступно з».
  • Все одно додати — примусовий запис із позначкою проблемності.

За дату та Журнал

  • «За дату» показує факти за вибрану дату.
  • Ред. — редагування, × — видалення запису.
  • Редагування з журналу захищене простим паролем.

4. Вкладка «План»

Використовується для попереднього планування майбутніх поїздок.

  • Дата — дата планової поїздки.
  • Виробнича дільниця — вибір із урахуванням циклограми.
  • Працівник — працівник для перевірки доступу.
  • Категорія — автоматично визначена категорія.
  • Додати / Оновити — створення або редагування плану.
  • Записати в журнал — переносить план у фактичний журнал.
  • Ред. — редагування, × — видалення плану.

5. Вкладка «Матриця / всі дільниці»

Всі виробничі дільниці за датою

  • Дата — дата перегляду стану дільниць.
  • Фільтр — пошук за назвою, номером або категорією.
  • Тиждень/стан — тиждень птиці або службовий стан.
  • Категорія — категорія для перевірки за матрицею.

Матриця

  • Рядок — попередня категорія, стовпець — наступна.
  • 0 — перехід можливий наступного дня.
  • 1, 2, 3 — кількість днів карантину.
  • х / x — спеціальне правило переходу.
  • * або ** — службові примітки.

6. Вкладка «Налаштування»

Тема

  • Світла, Темна, Тепла, М’ятна — змінюють вигляд без впливу на дані.

Автопідвантаження

  • Показує, які файли завантажені автоматично.
  • Очікувані файли: cycle.xlsx та workers.csv.
  • Назви файлів на GitHub мають збігатися повністю, включно з регістром.

Імпорти та експорти

  • Імпорт циклограми та працівників — ручне завантаження файлів.
  • Експорт JSON — повна резервна копія.
  • Імпорт JSON — відновлення з копії.
  • Експорт журналу CSV/Excel та працівників CSV — вивантаження даних.
  • Зберегти HTML з даними — автономний файл із поточними даними.
  • Очистити кеш PWA — скидання кешу після оновлення на GitHub.

Працівники

  • Поле вводу додає нового працівника вручну.
  • Додати додає працівника, якщо такого імені ще немає.
  • Показати / редагувати список відкриває модальне вікно зі всіма працівниками.
  • У модальному вікні можна шукати та видаляти працівників кнопкою Видалити. Історія журналу та вже створені плани не видаляються.

Обрані

  • Обрані працівники та дільниці показуються першими у списках вибору.

7. Типові ситуації

Не підтягується циклограма або працівники

  1. Переконайтесь, що cycle.xlsx і workers.csv лежать у корені репозиторію.
  2. Перевірте регістр літер у назвах.
  3. Відкрийте «Налаштування» і подивіться блок «Автопідвантаження».
  4. Натисніть «Очистити кеш PWA» або зробіть hard refresh.
  5. За потреби імпортуйте файли вручну.

Працівник заборонений для дільниці

  • Перегляньте «Доступно з» — це найближча дозволена дата.
  • За потреби можна додати примусово.
